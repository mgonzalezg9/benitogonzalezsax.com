# Task 3 Audit Matrix

Last updated: 2026-04-29

This matrix is the working document for the off-site authority audit.

How to use it:

- `Status` tracks whether the source is already found, pending owner verification, or missing.
- `Priority` helps us decide what to polish first.
- `Needs fixing` should stay short and concrete.
- `Owner data needed` marks the platforms where we need your access, screenshots, or exports.

## Status legend

- `Confirmed`: publicly found and verified enough to audit now
- `Pending`: likely exists or is important, but still needs owner access or confirmation
- `Missing`: not found yet and should be checked or created later

## Priority legend

- `P1`: strongest trust/citation sources, or highest risk if inconsistent
- `P2`: important support sources
- `P3`: useful later, but not urgent
