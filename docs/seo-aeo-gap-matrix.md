# SEO + AEO Gap Matrix

Last updated: 2026-04-12

## Current objective

- Homepage: rank for `saxofonista para bodas`
- Local pages: rank for `saxofonista para bodas en [ciudad]`
- Improve citation-readiness for Google AI Overviews and LLMs

## P1

- Increase extractable answer content before the sales funnel.
- Make service types more explicit in schema and visible copy.
- Keep homepage and local pages clearly separated by search intent.
- Reinforce city-page uniqueness in intro, trust, schema, and local references.

## P2

- Expand service schema with clearer `Service` and `OfferCatalog` coverage.
- Turn visible testimonials into machine-readable review signals.
- Standardize business identity across site and off-site profiles.
- Keep launched local pages only in sitemap while rollout is phased.

## P3

- Add more city-specific proof over time: venues, photos, reviews, media.
- Expand local page intros with more place-specific context where available.
- Add future programmatic support for pricing-intent pages only if they contain genuinely useful content.

## Funnel rule

This order stays fixed:

`Vídeos -> Repertorio -> Packs -> Opiniones -> FAQs -> Solicitar presupuesto`

All SEO/AEO shaping should happen before `Vídeos` or in machine-readable markup.

## On-site notes

- The homepage structure is strong and should be refined, not rebuilt.
- Local pages should keep the shared template and gain uniqueness mainly in metadata and pre-funnel content.
- Structured data should always match visible content.
