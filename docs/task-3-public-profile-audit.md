# Task 3 Public Profile Audit

Last updated: 2026-04-29

This report summarizes the public profile audit completed from publicly accessible sources.

Goal:

- verify which public profiles and citations already exist
- identify inconsistent NAP/entity signals
- flag older numbers, old market positioning, and missing links
- define the highest-value clean-up sequence

## Executive Summary

The public footprint is already stronger than average for a solo event musician:

- the website is live, indexed, and already acts as the strongest source of truth
- there are multiple public directory/citation sources already corroborating the brand
- there is meaningful coverage in both Spanish and English-facing sources

The main issue is not lack of presence.

The main issue is inconsistency:

- some profiles still present an older stage of the business
- years of experience, event volume, pricing, geography, and service framing do not always match the website
- some profiles lean too much into party/disco language and underplay weddings, cocktail, banquet, open bar, destination weddings, or corporate positioning

## Cross-Profile Consistency Findings

### Healthy signals

- the brand already appears on multiple public sources
- weddings and events are both present in several profiles
- Mazarrón / Murcia appears publicly on multiple sources
- there are real review signals on Musiqua and Encore

### Main inconsistencies

- experience:
  - some profiles say `3 años`
  - others say `10+ años`
  - others say `11 años`
- event count:
  - some profiles say `100 eventos`
  - others say `100 eventos el último año`
  - others say `200+ eventos`
- service framing:
  - some sources lean heavily into party / club / EDM
  - others are better balanced with weddings, cocktail and elegant formats
- geography:
  - some profiles show realistic coverage
  - some show over-broad or questionable coverage
- pricing:
  - visible public prices vary from `270€ - 800€`, `desde 350€`, `desde 400€`, `desde 468€`, and `£500`
  - variation itself is not necessarily wrong, but it needs to be intentional
