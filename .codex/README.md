# Codex Project Context

This directory mirrors the intent of the repository's Claude configuration in a Codex-friendly format.

Use:
- `AGENTS.md` as the primary instruction file
- `.codex/rules.md` for the shared project rules
- `.codex/architecture.md` for the site structure and boundaries
- `.codex/reviews/*` for focused review playbooks

The source of truth for these ideas still lives in:
- `CLAUDE.md`
- `.claude/`

Do not treat `.codex/` as a second product configuration system. It is a Codex-oriented translation of the existing project guidance.
